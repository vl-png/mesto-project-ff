# Mesto

Веб-приложение для обмена фотографиями с возможностью редактирования профиля и взаимодействия с карточками других пользователей.

[Демо](https://vl-png.github.io/mesto-project-ff/)

## Стек технологий:

- HTML, CSS, JavaScript

## Основные возможности:

- Редактирование профиля - изменение имени, описания и аватара пользователя.
- Галерея карточек - просмотр карточек с фотографиями от всех пользователей, открытие изображений в полноэкранном режиме.
- Система лайков - постановка и снятие лайков, отображение счетчика лайков в реальном времени.
- Управление карточками - добавление новых карточек и удаление собственных карточек.

## Установка и запуск:
Для запуска приложения выполните следующие шаги:

1. Склонируйте репозиторий:
    ```bash
    git clone https://github.com/vl-png/mesto-project-ff.git
    ```
2. Установите зависимости:
    ```bash
    npm install
    ```
3. Запустите приложение:
    ```bash
    npm run dev
    ```
